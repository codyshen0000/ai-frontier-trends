## 2. P0 规则

### 2.1 出图位置（布局仍照源码）

| 页面 | 可出图槽 | 无有用图时 | 禁止 |
|---|---|---|---|
| `/hot/` NO.01 hero | 1 张封面 | **空槽 / 无图状态**（文字+既有热度区照常；**不**把 sparkline 挪进封面位） | 给 NO.02 起加封面 |
| `/hot/` 其余卡 | 不出封面 | — | 用图或 sparkline「补」封面位 |
| `/daily/` 头条 | 1 张封面 | **空槽 / 无图状态**（**不**放 sparkline） | 给日报故事加封面 |
| `/daily/` 其余条目 | 不出封面 | — | — |

说明：源码组件里 NO.01 / 头条旁本来就有 sparkline 或热度区——那是**热度控件**，不是封面。v5 禁止的是「没封面就拿 sparkline 填封面位」。

### 2.2 价值门（硬门 · Cody）

对**允许出图的槽**，候选图必须先过价值门，再谈尺寸与借用顺序。

#### 有用（放）

| 类别 | 例子 |
|---|---|
| 模型样张 / 对比图 | 生成效果拼贴、前后对比、多模型并排 |
| 论文 / 研究图 | 论文 figure、评测曲线图、架构示意图（能看出「在讲什么」） |
| 产品功能截图 | 产品界面、功能演示帧（主体是功能，不是 Logo） |
| 官方解说图 | 官方博客/文档里的能力说明图、流程图 |

#### 无用（不放）

| 类别 | 例子 |
|---|---|
| Logo | 品牌方块、水印独图、纯字标 |
| 头像 | 人物大头照、演讲者肖像（主题就是该人且无其它信息时仍默认不放） |
| 装饰 / 氛围 | 纯背景、渐变、情绪图、无关库存感图 |
| OG / 社交预览 | 站点默认社交图、分享卡片图 |
| 无关图 | 与标题摘要主题对不上的任何图 |

#### 边界（写给开发 / 测试）

| 情况 | 判定 |
|---|---|
| 产品界面截图，角上有小 Logo | **有用**（主体是功能） |
| 纯 Logo 方图 / 徽章（shields、camo 徽章等） | **无用** |
| 评测条形图、Arena 榜图（正例：`refs/cody-valuable-img-example-aihot-deepseek.png`） | **有用** |
| 仅摘要文章（`body_mode = summary`） | 不出图、不借图（同源码） |
| SVG | **跳过**（防模糊；与 v4.1-c 一致） |
| 已知高度 **<240px** | **跳过**（防拉伸模糊） |
| 宽度未知 | **仅在价值门已通过后**，按 800px 计是否 ≥480（构建缩放用）；**价值门不通过则整张丢弃，不因「算成 800」而放行** |

### 2.3 选图流程（每槽）

1. 只在 §2.1 允许的槽处理。  
2. 按源码借用顺序收集候选（照 `stories.ts` / `reports.ts`）：  
   - **hot NO.01：** 代表文章 → 一手来源 → 已精选 → 评分高 → article_id  
   - **日报头条：** 该条本身 → 同事件一手 → 评分高 → article_id  
3. 丢掉：仅摘要、SVG、已知高 <240、明显 Logo/徽章 URL（如 shields.io / 纯 logo 文件名）。  
4. **对剩余每张做价值门**：落入「有用」才保留。  
5. 取**第一条过价值门**的图；若全部无用或无候选 → **无图状态**。  
6. **禁止**：自找图、换图、AI 生图、库存图、热链原图、用 sparkline/字段表/OG 凑封面。  
7. 价值门为规则 + 可解释启发式；交件须能说明「为何这张有用 / 为何不放」。边界拿不准 → 记入交件，**默认不放**，报产品，不私自放。

### 2.4 有用图的工程处理

仅当 §2.3 选出有用图时：

| 项 | 规则 |
|---|---|
| 缩放 | 构建期缩放（对应源码 hero 档，如 720 / 1200 / 1600）；webp（可加 jpg 兜底）；写入 `dist` |
| 标记 | `<img>` 必须带 `width` / `height` |
| 失败 | 下载或缩放失败 → **直接无图状态**；**禁止热链原图** |
| 费用 | 不用付费图片代理 / SaaS 缩放 |
| 拉伸模糊 | 截图可见拉伸或发糊 → **不通过** |

### 2.5 无图状态

- 封面槽留空（组件允许的空态）；**不**插入 sparkline、灰骨架、「暂无配图」大占位、字段表。  
- hot NO.01：卡片上原有的热度指数 / 24h 曲线区可保留在**热度控件位置**，不得挪到封面位冒充配图。  
- 日报头条：无封面时整页仍可读；不补任何图或曲线进封面位。

### 2.6 版式与对照截图

- 版式仍跟 MIT 壳组件（hot Lead、ReportLayout 头条）。有图时图在源码规定的封面位；无图时为空。  
- **交件对照（硬要求）：**  
  1. `/hot/` 1280：我方有图样例 **与** 无图样例各 ≥1（无图样例可用模拟或真实「仅 OG/Logo」条目）。  
  2. `/daily/` 头条 1280：同上。  
  3. ~390：`/hot/`、`/daily/` 各 ≥1。  
  4. 源站同位置对照（可选，有则更好）：只存**本地**（如 `/workspace/app-dev/engineering/…/evidence-<tip>/`），**不进公开仓 `refs/`**。

### 2.7 合规

- 无 AIHOT / MyHOT 名称、Logo、品牌。  
- 不整站 redeploy。  
- MIT 仅作算法/UI 参考，保留 LICENSE/NOTICE 要求。

## 4. 验收清单

### A. 价值与位置（产品 + 测试抽查）

- [ ] `/hot/`：仅 NO.01 可能有封面；NO.02 起无封面  
- [ ] `/daily/`：仅头条可能有封面；故事无封面  
- [ ] **每张已挂封面**：能归入 §2.2「有用」某一类；**一张无用图出现 = 本项失败**  
- [ ] **无封面槽**：原因是无候选或候选全无用；**不是**「用 sparkline 顶上」  
- [ ] 无热链原图；失败态直接无图  
- [ ] 无拉伸、无模糊（1280 与 ~390）

### B. 抽查法（测试审校 · 产品复检）

1. 交件中**所有已显示的封面**（通常 ≤2：hot NO.01 + 日报头条）各附：截图 + **一句话**（有用类别：样张/论文图/产品截图/解说图）。  
2. 每个无图槽附：一句话（无候选 / 全无用 / 下载失败）。  
3. **抽样 ≥5 条**在旧规则（≥480 自动挂）下会出图、但候选仅为 OG/Logo/装饰/徽章 的条目：确认 v5 下为**无图**。  
4. 任一条已挂封面落在「无用」列表 → **不通过**。  
5. 任一条用 sparkline 顶替封面 → **不通过**。  
6. 任一条热链原图 URL → **不通过**。

交件附件：`分类表`（classification sheet）——每条槽位一行：id / 候选摘要 / 价值判定 / 最终 URL 或「无图」/ 一句话理由。

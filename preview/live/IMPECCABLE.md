## Critique（Assessment A）

**设计特异性：通过。** 这是精选信息流：顶置「当前热点」编号面板 + 按日短卡片，不是日报报纸，也不是热点榜 hero。

### Nielsen（0–4）

| # | 启发 | 分 | 注 |
|---|---|---:|---|
| 1 | 系统状态可见 | 3 | 更新时间、当前「精选」、进热点榜 |
| 2 | 符合现实 | 4 | 来源名、另外 N 家、独立源计数；无假热度分 |
| 3 | 用户控制 | 3 | 外链原文、进榜单、原始看板 `#board` |
| 4 | 一致性 | 4 | 与 hot/daily 同暖纸 token；导航四项一致 |
| 5 | 防错 | 3 | 摘要截断；不注入图解；源 live.html 不改 |
| 6 | 再认而非回忆 | 3 | 来源作 kicker；日期作规则线 |
| 7 | 灵活高效 | 3 | 当前热点跳榜；按日扫读 |
| 8 | 美观克制 | 4 | 白卡 hairline、单色 teal、无渐变 |
| 9 | 纠错 | 3 | 空期文案；档案可回 `#curated` |
| 10 | 帮助 | 2 | 无「怎么读精选」；热点榜有热度说明 |

**概念：过关。** 1280 首屏含刊头、当前热点 Top 5、进热点榜、当日第一条短摘要。

### 优势

1. 导航四项与手机底栏一致：精选 / 热点 / 日报 / 更多。无 *HOT。  
2. 卡片是来源 + 标题 + 两行摘要 + 另外 N 家，不再铺研究墙。  
3. 当前热点是编号面板，不是四张大方块。

### 残留（非阻塞）

- **P2** 「另外 N 家」只在 `title`，点不开名单。  
- **P2** 精选流仍含当前热点条目，扫读会看到第二次。  
- **P3** 部分标题仍带研究口径（「观察」「不升档」）。

## 与 aihot 精选取舍（≤10）

1. 品牌是「前沿热点看板」，不写 AIHOT。  
2. 热度只暴露独立来源数，不画假 spark。  
3. 摘要截到约一句，不当成长文研究墙。  
4. 导航无「全部」；研究页收进更多。  
5. 不做半屏速览卡。  
6. 卡片不配 L2 说明性图（另一条线）。  
7. 当前热点固定 Top 5，安静日不自动隐藏（本期有足够条目）。  
8. 原始 Hub / 主线表仍在 `#board`。  
9. 手机底栏四项，不是 aihot 历史「精选/全部/日报/更多」。  
10. 暖纸 teal，不 redeploy 上游模板。

`npm run build` 与 `npm run verify:ia` 通过。
